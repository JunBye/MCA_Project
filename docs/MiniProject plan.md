# 미니 프로젝트 제안서

## 1. 목표 및 사용 시나리오

본 프로젝트의 목표는 음성을 주요 입력 모달리티로 활용하여 사람의 감정을 분석하고, 해당 감정이 진짜인지 가짜인지를 판별하는 모바일 애플리케이션을 개발하는 것이다. 앱은 두 가지 모드를 지원한다.

**모드 1 — 음성 전용 (Voice Only)**: 사용자가 음성을 녹음하거나 스트리밍으로 입력한다. 메인 음성 모델은 표현된 감정과 진짜/가짜 확률을 실시간으로 출력한다.

**모드 2 — 융합 (Voice + Face + PPG)**: 동일한 음성 모델에 별도로 학습된 얼굴 모델(Model A/B)과 카메라 기반 PPG 신호를 결합한다. 융합 결과는 음성 전용 결과와 비교되어 멀티모달 신호가 탐지 성능을 향상시키는지 평가한다.

이러한 분할의 핵심적인 동기는 실용성이다. 음성은 1차원 시계열 신호이기 때문에 라벨링된 영상이나 얼굴 표정 데이터셋을 수집하는 것보다 자체 데이터 수집이 훨씬 용이하다. 따라서 모드 1은 빠르게 학습 및 배포가 가능하며, 모드 2는 시각 및 생리학적 모달리티 추가로 인한 성능 향상을 정량화하기 위한 연구 비교 대상의 역할을 한다.

활용 가능한 사용 시나리오로는 소개팅, 면접 등 상대방의 진정한 의도를 파악하는 것이 중요한 대인 상황에서의 실시간 피드백 등이 있다.

## 2. 관련 연구

미세 표정 인식에 관한 기존 연구들은 미묘하고 짧은 얼굴 움직임이 일반적인 표정으로는 완전히 드러나지 않는 감정을 보여줄 수 있음을 시사한다. CASME II는 감정 및 액션 유닛 라벨이 포함된 자발적 미세 표정 샘플을 제공하며, 짧은 시간적 얼굴 변화를 통해 숨겨진 감정을 분석할 수 있음을 보여준다. SAMM 역시 자발적인 미세 표정 움직임에 초점을 맞추고 있으며, 고위험 상황에서 은폐된 감정이 어떻게 나타나는지를 이해하는 데 유용하다.

거짓말 탐지 연구에 따르면 얼굴 단서만으로는 충분하지 않은 경우가 많다. 거짓말은 여러 개의 약한 채널을 통해 새어 나온다: 목소리 떨림, 음높이 불안정성, 심박수 변화와 같은 생리적 각성 신호 등이다. 본 프로젝트는 음성을 주 채널로 사용하고, 얼굴과 PPG는 융합 환경에서 보조 모달리티로 다룬다.

모델 학습에 있어, 라벨이 부여된 진짜/가짜 데이터셋의 부족은 잘 알려진 과제이다. 이 문제를 해소하기 위해 준지도학습(Semi-supervised Learning)을 채택한다. SimCLR은 동일 샘플의 증강된 뷰를 대조함으로써 라벨이 없는 데이터로부터 유용한 표현을 학습한다. FixMatch는 의사 라벨링(Pseudo-labeling)과 일관성 정규화(Consistency Regularization)를 결합하여, 고신뢰도 예측만을 사용해 추가 학습 신호를 생성한다. 음성 데이터는 자체 수집과 증강(피치 시프트, 시간 마스킹, 노이즈 주입 등)이 용이하기 때문에, 이러한 접근 방식은 본 파이프라인에 특히 적합하다.

얼굴 브랜치(모드 2)의 경우, MediaPipe Face Mesh는 모바일 기기에서 실시간으로 468개의 3D 얼굴 랜드마크를 추출하여, 원본 카메라 프레임에 대해 전체 CNN을 실행하는 것보다 경량화된 대안을 제공한다. 카메라 기반 PPG 추출은 seeing-red 프로젝트(ssloxford/seeing-red)의 방법을 따르며, RGB 채널의 피부색 분산을 추적하여 스마트폰 카메라 영상에서 PPG 신호를 도출한다.

### 모드 1: 음성 전용 메인 모델

음성은 1차원 시계열 신호이다. 이는 대량의 라벨링된 데이터 수집(스크립트 기반 녹음 세션)과 강력한 데이터 증강(피치 시프트, 시간 늘리기, 가산성 노이즈, 룸 임펄스 응답)의 적용을 용이하게 한다. 음성 전용 모델은 본 프로젝트의 주요 결과물이다.

```
마이크 입력 (raw audio, 16kHz)
    ↓
특징 추출:
  - MFCC (40 계수)
  - 피치 컨투어 (F0)
  - 에너지 엔벨로프
  - Jitter / Shimmer (음성 떨림 지표)
    ↓
┌─────────────────────┬─────────────────────┐
│      Model A        │      Model B        │
│  음성 → 감정         │  음성 →             │
│  (7개 클래스)        │  진짜 / 가짜         │
└──────────┬──────────┴──────────┬──────────┘
           └──────────┬──────────┘
                   Model C
            "진짜 감정은 무엇인가?"
                      ↓
       [표면: 😊 행복 87%]
       [숨김: 😠 분노 62%]
       [진짜/가짜: 가짜 78%]
```

**음성을 주 모달리티로 선택한 이유:**

| 속성 | 음성 | 얼굴 |
| --- | --- | --- |
| 데이터 수집 비용 | 낮음 — 스크립트 기반 오디오 녹음 | 높음 — 통제된 영상 환경 필요 |
| 공개 데이터셋 가용성 | RAVDESS, CREMA-D (진짜/연기 라벨) | AffectNet (진짜/가짜 없음), MU3D (제한적) |
| 데이터 증강 | 용이 (피치, 노이즈, 시간) | 어려움 (조명, 자세 변화) |
| 거짓 신호 | 음성 떨림, jitter, 에너지 감소 | 미세 표정 (미묘함, 라벨링 어려움) |
| 모바일 추론 비용 | 낮음 (1D 신호) | 중간 (랜드마크 추출 + 인코더) |

### 모드 2: 융합 모델 (Voice + Face + PPG)

학습된 음성 백본은 얼굴 인코더와 PPG 신호로 확장된다. 얼굴 인코더는 자체 수집된 페어 데이터로 학습된 브리지 레이어를 통해 MediaPipe 3D 랜드마크를 음성 백본과 동일한 특징 공간으로 매핑한다. 카메라 기반 PPG는 seeing-red 방법(ssloxford/seeing-red)을 사용하여 추출한다.

**거짓 신호로서의 불일치(Discordance)**: 얼굴과 음성이 공유 특징 공간에서 서로 멀리 떨어진 임베딩을 생성할 때, 이러한 불일치 자체가 거짓의 증거가 된다.

```
d(face, voice) = 1 - cosine_similarity(z_face, z_voice)
높은 d → 얼굴과 음성이 다른 말을 하고 있음 → 가짜일 가능성 높음
```

```
[추론 — 모드 2]

카메라 → MediaPipe → 468×3 랜드마크
    → 얼굴 인코더 (MLP)
    → 브리지 레이어
    → z_face ∈ ℝ¹²⁸ ──────────────────────┐
                                            ↓
마이크 → MFCC/피치/jitter              융합 MLP
    → 음성 백본                        (Model C)
    → z_voice ∈ ℝ¹²⁸ ─────────────────────→ [감정]
                                            → [진짜/가짜]
카메라 → seeing-red PPG → BPM, HRV ────────→ [불일치]
```

**브리지 레이어 학습**: 소량의 자체 수집된 페어 데이터(음성과 영상을 동시에 녹화)만으로 충분하다. 브리지 레이어는 코사인 정렬 손실(cosine alignment loss)을 사용하여 z_face를 음성 특징 공간으로 매핑하는 법을 학습한다.

## 4. 구현 계획

### 데이터셋

| 데이터셋 | 모달리티 | 라벨 | 용도 |
| --- | --- | --- | --- |
| **RAVDESS** | 음성 + 영상 | 8가지 감정, 진짜/연기 | 음성 백본 학습 (Model A, B) |
| **CREMA-D** | 음성 | 6가지 감정, 진짜/연기 | 보조 음성 학습 |
| **자체 수집** | 음성 + 얼굴 + PPG | 스크립트 기반 진짜/가짜 시나리오 | 브리지 레이어 + Model C |

AffectNet과 MU3D는 본 계획에서 필요하지 않다. RAVDESS와 CREMA-D는 진짜/연기 구분이 있는 음성 데이터를 직접 제공하며, 이는 추가적인 데이터셋 정렬 없이 Model A와 B의 요구사항을 충족한다.

**자체 수집 스크립트** (4명 이상의 참가자, 5초 클립, 조명 및 거리 통제):

| 시나리오 | 라벨 |
| --- | --- |
| 좋아하는 음식에 대해 이야기 | 진짜 행복 |
| 싫어하는 것을 칭찬 | 가짜 행복 / 숨김: 부정 |
| 무서운 영상을 보고 "괜찮아요" | 가짜 중립 / 숨김: 공포 |
| 부끄러운 기억 회상 | 진짜 당황 |

### 모델 아키텍처

### 음성 백본 (메인 모델 — RAVDESS + CREMA-D 학습)

```
원본 오디오 (16kHz)
    ↓
MFCC (40 계수) + 피치 + 에너지 + Jitter/Shimmer
    ↓
경량 LSTM (2 레이어, hidden=128) 또는 1D-CNN
    ↓
z_voice ∈ ℝ¹²⁸
```

### 얼굴 인코더 + 브리지 레이어 (모드 2 — 자체 수집 페어 데이터로 학습)

```
카메라 프레임
    → MediaPipe Face Mesh
    → 468 × 3 랜드마크 = 1404차원 벡터
    → 얼굴 인코더: MLP (1404 → 512 → 256 → 128)
    → 브리지 레이어: 선형 투영 + LayerNorm
    → z_face ∈ ℝ¹²⁸   (코사인 손실로 음성 공간에 정렬)
```

### Model A — 감정 분류기 (7개 클래스)

고정된 음성 백본을 사용하여 RAVDESS/CREMA-D 감정 라벨로 파인튜닝한다.
출력: 행복, 슬픔, 분노, 공포, 혐오, 놀람, 중립.

### Model B — 진짜/가짜 분류기

고정된 음성 백본을 사용하여 RAVDESS의 연기/진짜 라벨로 파인튜닝한다.
출력: 진짜/가짜 확률.

### Model C — 숨겨진 감정 추론

→ 이것을 Hidden Label 추출이 아니라, Model A에서 얻은 감정(카메라 기반)과 음성 기반으로 얻어낸 추론 결과가 일치하는지로 진짜/거짓을 판단하는 것이 주 목적. Hidden Emotion은 사실상 폐기.

```
입력 (모드 1):
  z_voice (128) + Model A 로짓 (7) + Model B 로짓 (2)
  → 총 137차원

입력 (모드 2, 추가):
  z_face (128) + d(face, voice) (1) + PPG 특징: BPM, HRV (2)
  → 총 268차원

아키텍처: MLP (입력 → 64 → 32 → 7)
출력: 추론된 숨겨진 감정 (7개 클래스)
```

### PPG 추출 (모드 2)

카메라 기반 PPG 신호는 **ssloxford/seeing-red**를 사용하여 추출하며, 이는 뺨 영역의 RGB 피부색 분산을 추적하여 스마트폰 카메라 영상에서 생리학적 신호를 도출한다. BPM과 HRV는 추출된 PPG 파형에서 계산되어 Model C에 보조 특징으로 전달된다.

### 준지도 학습 파이프라인

1. **SimCLR 사전학습**: RAVDESS + CREMA-D 데이터에 라벨 없이 적용. 오디오 증강: 시간 마스킹, 피치 시프트 ±2 반음, 가산성 가우시안 노이즈. 이를 통해 공유 음성 특징 공간을 구축한다.
2. **지도 파인튜닝**: 고정된 SimCLR 백본을 사용하여 라벨링된 음성 데이터로 Model A(감정)와 Model B(진짜/가짜)를 파인튜닝한다.
3. **FixMatch 의사 라벨링**: 연기/가짜 음성 샘플에 Model A를 적용. 신뢰도 0.95 이상의 의사 라벨을 채택하여 Model C 학습용 `{가짜, 숨겨진 감정}` 페어를 생성한다.
4. **브리지 학습 + Model C**: 자체 수집된 페어 데이터로 얼굴 인코더와 브리지 레이어를 학습. 의사 라벨링된 음성 샘플과 자체 수집 데이터로 Model C를 학습한다.

### 모델 최적화

TensorFlow Lite INT8 사후 학습 양자화(post-training quantization)를 모든 모델에 적용한다. 모드 1은 MFCC 특징을 사용하고(원본 이미지가 아님), 모드 2의 얼굴 입력은 저차원 랜드마크 좌표를 사용하므로, 정확도 저하 2% 미만으로 모델 크기 75% 감소를 목표로 한다.
